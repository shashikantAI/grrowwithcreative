Meta Astryx with Claude Code: install lines + the prompt + 7 themes (keyword THEME)

Repo: github.com/meta/astryx (MIT, free, beta) · Docs: astryx.atmeta.com. Meta's own design system, opened to everyone. It needs React 19 or later. All commands below were run on 2026-11-12 with Astryx 0.7.14.

1. Install (in your React project)

npm install @astryxdesign/core @astryxdesign/theme-neutral @stylexjs/stylex
npm install -D @astryxdesign/cli

2. Tell Claude Code about it

npx astryx init --agent claude

3. The prompt I used (paste in Claude Code)

Build an admin dashboard for "ChaiDaily", a chai delivery startup in Mumbai, as the home page of this Vite React app (replace the starter App). It needs: a left sidebar with navigation, a top bar with search and a dark mode toggle that works, 4 KPI cards (orders today, revenue in rupees, active riders, average delivery time), a weekly orders chart, and a recent orders table with status badges. Use realistic sample data. Make it look like a professional product. When you are done, make sure `npm run build` passes.

4. Change the whole design with one word

npm install @astryxdesign/theme-matcha
npx astryx theme add matcha
npx astryx theme use matcha
neutralbutterchocolatematchastonegothicy2k

The 7 theme names. Put any name in place of matcha.

5. Honest notes from my own test (same prompt, with and without Astryx)

  • With Astryx: 595 lines of code and 0 CSS files. Without: 1,184 lines, 749 of them CSS.
  • It did not look better than the plain build. Both dashboards looked professional.
  • It took longer to build, and the JS file was bigger (1.24 MB vs 231 kB).
  • Worth it when the design will change often. For one small page you do not need it.
