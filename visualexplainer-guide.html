Visual Explainer for Claude Code: the 2 install lines + 10 commands cheat sheet (keyword EXPLAIN)

Repo: github.com/nicobailon/visual-explainer (MIT, free; 10,837 stars on 2026-11-07). It is a Claude Code skill: a rules file Claude reads on install that says "when the answer would be a big table or a diagram, do not print it in the terminal, build an HTML page and open it in the browser".

1. Install (paste inside Claude Code, one line after the other)

/plugin marketplace add nicobailon/visual-explainer
/plugin install visual-explainer@visual-explainer-marketplace

Claude replies "Successfully added marketplace", then "Successfully installed plugin". Done. Restart Claude Code if the commands below do not autocomplete.

2. The 10 commands (type them inside Claude Code)

1
/visual-explainer:generate-web-diagram <topic>
A figure-first HTML page for any topic, opened in your browser. The diagram in the reel.
2
/visual-explainer:generate-web-diagram <topic> --slides
The same content as a slide deck. One word, same page becomes a presentation.
3
/visual-explainer:generate-slides <topic>
A self-contained HTML slide deck.
4
/visual-explainer:diff-review [branch | commit | range | PR]
A visual review of code changes, each fix as accept / leave in the page. The "abhi commit mat karo" page.
5
/visual-explainer:plan-review
Compares an implementation plan with the current codebase; fixes to accept or reject in the page.
6
/visual-explainer:generate-visual-plan <feature>
An interactive implementation plan you answer in place.
7
/visual-explainer:project-recap [2w]
A visual project recap for context switching.
8
/visual-explainer:state-machine
Draws a state machine from the code itself and replays every rule it breaks.
9
/visual-explainer:compare <A> <B> ...
Compares options side by side, recommends one, you pick in the page.
10
/visual-explainer:fact-check <document>
Checks a generated document against the real code and git history.

Bonus: /visual-explainer:generate-video <topic> makes a narrated MP4 explainer (extra setup, see the repo README).

3. Karpathy's 4 formats (the idea behind it)

Andrej Karpathy, 2 Oct 2026 (8.1M views): x.com/karpathy/status/2105819303471976479

1 · text2 · diagram3 · HTML page4 · short video

Ask the AI for the format that is easiest to read, not the easiest to generate. Text is the worst format to read a lot of; a page you can click is better; a short video is best. This repo makes Claude Code do the middle two by default.

4. Honest notes from my own test (2026-11-07)

  • Diagram page: 176 s, about $1.20 of Claude usage. Diff review: 163 s, about $1.50. 14-slide deck: 377 s, about $1.90. Not instant, not free in tokens; the repo itself is free.
  • Auto-trigger (a plain question giving a page without a command) did not fire in 2 of my 2 tests. The README says "results vary by model capability". Type the command when you want a page.
  • The pages are local HTML files in ~/.agent/diagrams/ (Windows: C:\Users\<you>\.agent\diagrams\). They stay on your machine.
  • Works best on a repo with real code and git history; on a toy folder the pages are thin.
