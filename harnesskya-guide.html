Reel: "Is aadmi ke paas sabse taaqatwar ghoda hai…" (harness engineering). Model = ghoda. Harness = saaz. Ye file tumhare AI coding agent ko bina test chalaye "done" bolne nahi deti.

Kaise use karo

  1. Neeche wala block copy karo.
  2. Apne project ke root mein CLAUDE.md (Claude Code) ya AGENTS.md (Codex / Cursor / doosre agents) naam se save karo.
  3. Section 5 mein apni language, test command aur run command bharo.
  4. Jab bhi AI galti kare, us galti ki ek line "Galtiyan jo dobara nahi" mein jod do (Mitchell Hashimoto ka formula).

# Project rules for the AI agent

## 1. Shuru karne se pehle (folder ka naksha)
- Pehle folder structure dekho (ls / tree) aur ye file poori padho.
- Kaam shuru karne se pehle 3-5 line ka plan likho: kya badlega, kaunsi files, kaise test hoga.

## 2. Kaam karte waqt
- Ek baar mein ek chhota badlaav. Har badlaav ke baad test chalao.
- Jo command chalate ho, uska output padho. Error ho toh pehle samjho, phir fix karo.
- Bina pooche files delete mat karo, git history rewrite mat karo, secrets ko print mat karo.

## 3. Khatam karne se pehle (checklist)
- [ ] Tests chalaye aur pass hue (command + result likho).
- [ ] Jo maanga tha wahi kiya, us se zyada nahi.
- [ ] Koi debug code / commented code reh toh nahi gaya.
- [ ] Short summary: kya badla, kya test hua, kya baaki hai.
- "Code dekh ke sahi lag raha hai" = done NAHI hai. Test = done.

## 4. Ek hi galti baar-baar (alarm)
- Agar ek hi file ko 3 baar edit kar chuke ho aur problem wahi hai: RUKO.
  Approach badlo, ya user se poocho. Wahi tareeka thoda badal ke 10 baar try mat karo.

## 5. Project ki jaankari
- Language / framework: <yahan likho>
- Test command: <npm test / pytest / ...>
- Run command: <npm run dev / python main.py / ...>
- Style: <formatter, naming rules>

## 6. Galtiyan jo dobara nahi (har galti ke baad ek line jodo)
- <example> API keys kabhi code mein mat likho, .env use karo.
- <example> UI badalne ke baad screenshot lekar check karo.
