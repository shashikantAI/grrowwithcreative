GitHub ka Iceberg — 5 free tricks, step by step (shashikant.ai)

Tested on 4 Oct 2026. Sab free. Har step real hai, reel mein jo dikha wahi.

1. Roz ka hot repo — GitHub Trending

Open github.com/trending. "Date range" → Today / This week. Language filter se apni language chuno.

Tip: is page ko bookmark kar lo, roz 1 minute dekho.

2. Code ka diagram — gitdiagram

Kisi bhi repo ke URL mein github ki jagah gitdiagram likho:

github.com/facebook/react → gitdiagram.com/facebook/react

Poora codebase ek clickable diagram ban jaata hai. Free, login nahi chahiye.

3. VS Code, bina install — press "."

GitHub pe koi bhi repo kholo aur keyboard pe . (dot) dabao. Ya URL mein github.com ki jagah github.dev likho.

Browser mein VS Code khul jaata hai: files padho, search karo, edit karo, commit karo.

Pehli baar "GitHub Repositories wants to sign in" aaye toh Allow karo.

4. Free computer, browser mein — Codespaces

Apne repo pe: Code → Codespaces → Create codespace on main.

Ek poora Linux machine browser mein (2 core, 8 GB RAM) with terminal, Python, Node, Docker.

Free plan: 120 core-hours + 15 GB storage har mahine. Kaam khatam → codespace Stop karo (github.com/codespaces → ⋯ → Stop), warna hours chalte rehte hain.

5. GitHub khud chalaye — Actions schedule

Repo mein Add file → Create new file → naam: .github/workflows/daily.yml → ye paste karo:


name: roz-subah-9-baje
on:
  schedule:
    - cron: "30 3 * * *"   # 09:00 IST, roz (cron UTC mein hota hai)
  workflow_dispatch:        # "Run workflow" button
permissions:
  contents: write
jobs:
  kaam:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: kaam karo
        run: echo "$(TZ=Asia/Kolkata date) - GitHub ne khud chala diya" >> log.txt
      - name: save
        run: |
          git config user.name "github-actions[bot]"
          git config user.email "github-actions[bot]@users.noreply.github.com"
          git add log.txt && git commit -m "roz ka kaam" && git push

Commit karo → Actions tab → Run workflow → ~10 second mein green ✅.

run: wali line mein apni script daalo (python script, backup, report, kuch bhi).

Public repo = unlimited free minutes. Private repo = 2,000 min/month free.

Live demo: github.com/shashikantAI/github-iceberg-demo (roz 9 baje log.txt mein line add hoti hai).

Ek sach

Codespaces ke 120 ghante Free plan ki limit hai, uske baad paisa lagta hai. Actions public repo mein free hai.
