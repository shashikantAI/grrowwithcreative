PHP2Shell check — apni website 5 minute mein check karo (shashikant.ai)

Reel ke saath wala guide. Facts 22 Oct 2026 ke hain (sources neeche). Is guide mein sirf check aur fix hai, koi hacking step nahi.

Kya hua (1 line)

PHP ke andar ek purana memory bug (2020 mein mila, 2024 mein dobara mila) AI ki madad se exploit karne layak ban gaya. Score 9.2/10 (CVSS). 21 Oct 2026 ko fix aaya, aur Europe ki kai sarkari websites precaution mein offline gayi.

Step 1 — apna PHP version dekho

WordPress: Dashboard → Tools → Site Health → Info → Server → line PHP version.

cPanel hosting: Software → MultiPHP Manager (ya "Select PHP Version") → current version.

Developer ho: server pe php -v chalao.

Step 2 — safe version se milao

tumhari series safe (fix) version ya usse naya
8.5 8.5.12
8.4 8.4.27
8.3 8.3.36
8.2 8.2.35
8.1 ya purana official support khatam — host se 8.3/8.4 pe upgrade maango

Tumhara version isse purana hai? → Step 3.

Step 3 — host / developer ko ye message bhejo

English (copy):

Hi, please update the PHP version on my server to the patched release for PHP2Shell
(CVE-2026-109618 / CVE-2026-109619): 8.5.12, 8.4.27, 8.3.36 or 8.2.35 or newer.
My site currently shows PHP <your version>. Please confirm once done. Thanks!

Hinglish (copy):

Hi, mere server ka PHP PHP2Shell (CVE-2026-109618 / 109619) ke patched version pe update kar do —
8.5.12, 8.4.27, 8.3.36 ya 8.2.35 (ya naya). Abhi site pe PHP <tumhara version> dikh raha hai. Ho jaye toh batana. Thanks!

Yaad rakho

  • WordPress auto-update sirf WordPress aur plugins update karta hai, server ka PHP nahi. PHP hosting company / server wala update karta hai.
  • Har website hack nahi hui: zyada tar public attacks ko ek aur bug bhi chahiye. Par risk lene ka koi faayda nahi; update free hai.
  • Update ke baad Site Health dobara kholo aur naya version confirm karo.
