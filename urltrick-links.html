GitHub URL trick: the 3 links

Kisi bhi public GitHub repo ka URL lo, github.com ki jagah neeche wala domain likho. Bas. Example repo: github.com/facebook/react

1 · Architecture diagram

gitdiagram.com

Link: https://gitdiagram.com/facebook/react

github.com/OWNER/REPO → gitdiagram.com/OWNER/REPO

  • Poore codebase ka interactive architecture diagram, 20–30 seconds mein.
  • Enable zoom se andar jao, Export se PNG ya Mermaid code download karo.
  • Free for public repos. Private repo ke liye apna GitHub token lagana padta hai.

2 · AI-written docs + Q&A

deepwiki.com

Link: https://deepwiki.com/facebook/react

github.com/OWNER/REPO → deepwiki.com/OWNER/REPO

  • Repo ki poori documentation, AI (Devin) ki likhi hui, with links to the exact source files.
  • Neeche Ask Devin about … box mein sawaal poocho — jawab seconds mein, no login (Fast mode).
  • Popular repos already indexed; nayi repo ke liye Index your code click karo (free for public repos).

3 · Your AI agent reads the real repo

gitmcp.io

Link: https://gitmcp.io/facebook/react

github.com/OWNER/REPO → gitmcp.io/OWNER/REPO  (note: .io, not .com)

Ye ek MCP server hai us repo ke liye. Cursor / Claude Code / Windsurf / VS Code isse connect karke actual code padh ke jawab dete hain — guess nahi.

Cursor — ~/.cursor/mcp.json mein add karo:

{
  "mcpServers": {
    "react Docs": {
      "url": "https://gitmcp.io/facebook/react"
    }
  }
}

Claude Code — terminal mein:

claude mcp add --transport sse react-docs https://gitmcp.io/facebook/react
  • Free, open source, no login. Public repos only.
  • Page pe hi Cursor / Claude Desktop / Windsurf / VS Code / Cline ke ready-made config snippets hain.
