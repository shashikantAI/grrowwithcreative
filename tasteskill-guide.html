1. Install (inside your project folder) 

npx skills add https://github.com/Leonxlnx/taste-skill --skill design-taste-frontend -a claude-code -y

Needs Node.js. Then open Claude Code in the same folder; the skill loads by itself when you ask for a page. Repo: github.com/Leonxlnx/taste-skill (94K+ stars on 11 Oct 2026)

2. My prompt (change the business) 

Build a single-file landing page (index.html, inline CSS and JS, no build step) for "ChaiDaily", a Mumbai chai subscription that delivers fresh masala chai to offices every morning. Include: hero with headline and call to action, 3 benefits, 2 pricing plans in rupees, customer testimonial, footer. Phone-first, also good on desktop.
Do not invent phone numbers, addresses or reviews; leave clear placeholders like [YOUR NUMBER].
Use no stock photos; leave [YOUR PHOTO] boxes.

The last two lines are my fix for the twist in the reel.

3. Count the mistakes yourself (free)

npx impeccable detect

Run it in the folder before and after. Mine: 15 → 5.

4. Before you publish: 4 checks

  1. Every photo is yours. The AI picked random placeholder photos (a café for chai, a flyover, a leaf).
  2. The phone / WhatsApp number is yours. It made one up, and it could be a real stranger's number.
  3. Prices, address and reviews are real.
  4. Open it on your phone once.
