TradingAgents: a 12-AI trading company on your own laptop

Repo: github.com/TauricResearch/TradingAgents · free and open source (Apache-2.0) · 1,18,000+ GitHub stars.

What it is

  1. Analyst team (4): market/chart, social mood (Reddit, StockTwits), news, fundamentals (balance sheet).
  2. Bull vs bear (2) argue "khareedo" vs "mat khareedo", then a research manager picks a side.
  3. Trader writes the plan, the risk team (3) looks for danger, the portfolio manager gives the final answer (Buy / Overweight / Hold / Underweight / Sell).

Option A: free, on your own computer (what I used)

Needs Python 3.11+, about 10 GB free disk, and ideally 16 GB RAM or a GPU.

  1. Install Ollama from ollama.com, then download a model:
    ollama pull qwen2.5:14b
  2. Get the code and install it:
    git clone https://github.com/TauricResearch/TradingAgents.git
cd TradingAgents
python -m venv .venv
.venv\Scripts\activate
pip install .

    Mac/Linux: use source .venv/bin/activate instead of the 4th line.

  3. Run it:
    tradingagents
    Pick Ollama as the provider, choose "Custom model ID" → qwen2.5:14b, ticker RELIANCE.NS, and a date.

Option B: with ChatGPT, Claude or Gemini

Better answers, costs API money. Set one key, open a new terminal, run tradingagents and pick that provider:

setx OPENAI_API_KEY "your-key"
setx ANTHROPIC_API_KEY "your-key"
setx GOOGLE_API_KEY "your-key"

Have ChatGPT Plus? Run tradingagents login chatgpt and choose "Subscription" instead of a key.

Indian shares

Use the Yahoo Finance ticker: NSE = .NS (e.g. RELIANCE.NS, TCS.NS), BSE = .BO.
