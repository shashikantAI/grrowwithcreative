The prompt (copy all of it)

Build a single self-contained HTML file called editor.html: a fictional, cinematic desktop app called "REEL AGENTS",
an AI video editor where 6 AI agents edit a vertical reel live, all at the same time. It will be filmed on a monitor
for a social media video, so it must look like a real, premium, professional editing app (think DaVinci Resolve meets
a mission-control dashboard), dense with detail but clean.

CANVAS
- Exactly 1920 x 1080, dark UI (#0B0B0F base, #15151C panels, 1px #26262F borders), one accent colour #C6F432 (lime),
  small secondary colours only for track types. Font: Inter / system sans for UI, JetBrains Mono / monospace for numbers.
- No external libraries, no network requests. Everything in one file (HTML + CSS + vanilla JS + inline SVG).
- The only external files sit in the same folder: reel.mp4 (a vertical 9:16 video, sound off) and an optional
  captions.json ([{"start":0.0,"end":0.4,"word":"this"}, ...]). Read the video path from the URL parameter ?src=
  (default reel.mp4). If captions.json is missing, show built-in demo captions. ?fx=0 turns the wild edits off.
- If the video cannot load (for example in a sandboxed preview), the program monitor plays a built-in animated
  stand-in (a neon SVG talking-head with a moving mouth and the same wild edits) on a 30-second clock, so the app
  NEVER shows an empty or broken monitor.
- Everything is driven by ONE clock: the loop time equals the video's currentTime, so the same URL always shows the
  same frame at the same second (it will be screen-recorded several times and must line up).

LAYOUT (all panels visible at once)
- Top bar: app name, menu (File, Edit, Clip, Color, Captions, Audio, Agents), project name "reel_v1", a live pill
  "6 AGENTS LIVE" with a pulsing dot, and an "Export" button.
- Left: Media pool (grid of 12 clip thumbnails with filenames and durations, plus an audio section with music and SFX files).
- Centre: Program monitor showing reel.mp4 playing in a 9:16 frame, with live captions burned on top
  (2-3 words at a time, bold condensed uppercase, the key word in lime), a timecode counter above it.
- Right of centre: a live audio waveform meter, a vectorscope with a moving trace, and a loudness meter reading toward -14 LUFS.
- Far right: Color panel with 3 colour wheels (Lift, Gamma, Gain) and sliders (Temp, Tint, Contrast, Saturation, Exposure);
  below it a Captions style picker (4 preset chips) and colour swatches.
- Bottom: a multi-track timeline (TEXT, SFX, B-ROLL, A-ROLL, GRADE, VOICE, MUSIC) with a playhead, a time ruler,
  and clips that appear on the tracks as the agents work.
- Bottom-left panel "AGENT ACTIVITY": a scrolling log, one line per action, e.g. "00:04  cutter-01  removed 0.6s silence  ✓".
- Status bar: "6 agents · 142 edits · GPU 61% · render ready".

THE SHOW (a scripted animation that lasts exactly as long as reel.mp4, then loops)
- 6 agent cursors (cutter-01, grade-01, caption-01, broll-01, sfx-01, mix-01), each a mouse pointer with a small
  coloured name tag. They glide with smooth eased motion (never teleport) and work at the same time in different panels:
  - cutter-01 slices clips on the A-ROLL track (a blade line flashes, the gap closes).
  - grade-01 drags the colour wheels and sliders; the program monitor's grade visibly shifts (CSS filters on the video).
  - caption-01 clicks a caption preset; the captions on the video change style.
  - broll-01 drags thumbnails from the media pool onto the B-ROLL track.
  - sfx-01 drops small SFX blocks on the SFX track (whoosh, pop) with a tiny waveform each.
  - mix-01 pulls the music fader; the loudness meter settles at -14.0 LUFS.
- Every agent action writes a line to AGENT ACTIVITY and adds to the edit counter.
- The timeline fills up from empty (0 %) to a complete, colourful edit (85 % of the video). At 85 % an
  "EXPORT COMPLETE ✓" toast slides in; at 100 % everything resets with the video and the loop starts again.
- Subtle life everywhere: meters bounce, the playhead moves, numbers tick, hover glows. Nothing is ever fully still.

WILD EDITS INSIDE THE PROGRAM MONITOR (the reel being edited must look heavily, boldly edited, changing every 1-2 s)
- Punch-in zooms on the face (alternating in/out), with a quick motion blur on each punch.
- Split-screen moments: top half a neon B-roll card (phone UI mock, glowing hourglass, chat bubbles drawn in SVG), bottom half the face.
- Neon shapes: pink hexagons and lime rings that pop in on the beat, a glitch/RGB-split flash on hard cuts.
- Big caption slams: one huge word fills the frame with a blur-in (e.g. "ZERO", "10X"), then shrinks back to normal captions.
- Grade jumps: neon purple → teal → warm, driven by grade-01's colour wheels.

BIZARRE TOUCHES (make it unforgettable, not just pretty)
- The agents talk: small chat bubbles pop above the cursors and argue about the edit
  ("grade-01: too orange", "caption-01: make it lime", "cutter-01: cut the 'umm'", "mix-01: louder!"), max 1 bubble every 2 s.
- Agent swarm: at 60 % of the video, a "SPAWN 12 MORE AGENTS" button is clicked and 12 extra cursors burst out of it like a flock,
  zip across the timeline finishing the edit in 3 seconds, then disappear one by one.
- The playhead is physical: when it hits a cut, the clip edges spark (tiny lime particles).

QUALITY BAR
- It must hold up to a close-up camera shot: crisp 1px lines, aligned grid, consistent spacing, real-looking labels and
  numbers (timecodes, dB, file names), no lorem ipsum, no overlapping text, no empty panels.
- Smooth 60 fps animation (requestAnimationFrame), no layout jumps.

Before you finish, walk through the loop at 0 %, 30 %, 60 % and 90 % in your head against your code, fix anything
broken or ugly, then give me the complete file.

Honest notes

  • The editor is an animation. The agents and the timeline are scripted; it does not really edit your video.
  • Fable 5.2 built the editor only. The dark room, the monitor and the camera dive in my post were made in Blender.
  • The result was one file of about 87 KB with no libraries. Your result will look different each run.
  • The colour grade is strong: skin turns teal or purple when the grade agent works.
  • It is a long run. Mine used a visible part of my weekly limit on a paid plan.
  • Tricks: editor.html?fx=0 turns the wild edits off, ?src=other.mp4 plays another file, Space pauses.
