AI lip sync on your own face: Wav2Lip + LatentSync setup

The same 2 free models from my Ramayana reel. Personal use only, on your own face.

Wav2Lip is the classic one to learn how lip sync works. LatentSync looks far more natural. Both run free on your own PC.

You need

  1. Windows/Linux PC with an NVIDIA GPU (6 GB+ VRAM for Wav2Lip, ~5–8 GB for LatentSync 1.5), Python 3.10–3.12, Git, ffmpeg.
  2. A 4–10 s video of your face: head steady, looking at the camera, no hands near the mouth, no jump cuts.
  3. The new audio line (wav). Keep it no longer than the video.

Option A: Wav2Lip (lightest)

  1. Get the code (github.com/Rudrabha/Wav2Lip):
    git clone https://github.com/Rudrabha/Wav2Lip
cd Wav2Lip
python -m venv .venv
.venv\Scripts\activate
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
pip install librosa opencv-python numpy scipy tqdm numba
  2. Weights: download wav2lip_gan.pth from the "Getting the weights" table in the repo README into checkpoints/, and the face detector s3fd.pth into face_detection/detection/sfd/ (link also in the README).
  3. Two small fixes for new Python versions:
    · audio.py: use keyword arguments in librosa.filters.mel(sr=hp.sample_rate, n_fft=hp.n_fft, n_mels=hp.num_mels, fmin=hp.fmin, fmax=hp.fmax)
    · face_detection/utils.py: replace np.int with np.int64
  4. Run:
    python inference.py --checkpoint_path checkpoints/wav2lip_gan.pth --face my_face.mp4 --audio line.wav --pads 0 20 0 0
    Output: results/result_voice.mp4. The mouth is drawn at 96 px, so it looks soft; that is the model's limit.

Option B: LatentSync 1.5 (most natural)

  1. Get the code and weights (github.com/bytedance/LatentSync; Linux or WSL2 is easiest):
    git clone https://github.com/bytedance/LatentSync
cd LatentSync
source setup_env.sh
  2. Put your video and audio paths in inference.sh (--video_path, --audio_path), then run ./inference.sh.
  3. Settings that worked best in my test: 25 inference steps, guidance scale 2.0.
  4. On plain Windows two packages (insightface, decord) have no ready installer for new Python; use WSL2 or the LatentSync node for ComfyUI instead.

Tips from my test

  1. Steady, front-facing head = much better lips. Hands moving in front of the face confuse both models.
  2. If the audio is longer than the video, the tools play the video back and forth and your head visibly reverses. Trim the silence instead.
  3. Only the mouth area should change. If eyes or skin look plastic, paste back the mouth region only.
