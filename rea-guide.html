REA: setup steps + my Netflix test file

Tested 12 Oct 2026 on Windows 11 · rea-agents 6.4.0 · Google Chrome · netflix.com/in opened for 30 seconds, no login, no clicks

121messages in 30 s
76to other companies
18to TikTok (most)

1. What you need

  1. Node.js 18 or newer (nodejs.org, LTS button). Check: node -v
  2. Google Chrome installed (normal install path).
  3. Python 3 only for step 4 (the counting script). Optional.

REA is free and open source: github.com/morluto/rea (#1 on GitHub Trending, 12 Oct 2026). Nothing is installed globally; npx downloads it the first time.

2. Save the test file as netflix.json 

{
  "browser": { "mode": "launch", "executable_path": "C:/Program Files/Google/Chrome/Application/chrome.exe" },
  "start_url": { "url": "https://www.netflix.com/in/" },
  "actions": [
    { "step_id": "wait", "action": "wait_for_timeout", "duration_ms": 30000 }
  ],
  "capture": { "at_end": ["url", "screenshot"], "events": ["network"] }
}

Windows: keep the forward slashes / in the Chrome path (backslashes break the JSON). Mac: /Applications/Google Chrome.app/Contents/MacOS/Google Chrome. Any other site: change only the url.

3. Run REA (same folder) 

npx -y rea-agents@6.4.0 capture-browser-scenario netflix.json --format json > netflix-capture.json

A Chrome window opens, waits 30 seconds and closes. netflix-capture.json now holds every request the page sent: the host, the path and the order.

4. Count where the messages went 

import json, sys, collections, urllib.parse
d = json.load(open(sys.argv[1], encoding="utf-8"))
reqs = [e for e in d["normalized_result"]["events"]["items"] if e.get("kind") == "request"]
site = sys.argv[2] if len(sys.argv) > 2 else "netflix"
hosts = collections.Counter(urllib.parse.urlparse(e["url"]["url"]).hostname or "" for e in reqs)
out = {h: c for h, c in hosts.items() if site not in h and "nflx" not in h}
print(len(reqs), "requests,", sum(out.values()), "went to other companies' servers")
for h, c in sorted(out.items(), key=lambda x: -x[1])[:25]:
    print(f"{c:4}  {h}")

Save as count.py, then: python count.py netflix-capture.json netflix. For another site, pass its name as the last word (for example flipkart).

My output started with: 121 requests, 76 went to other companies' servers · 18 analytics.tiktok.com · 6 tr.snapchat.com · 3 match.adsrvr.org (The Trade Desk). Your numbers will differ a little run to run.

5. Want to use REA with Claude Code / Codex?

npx rea-agents setup

The repo README shows this command for connecting REA to your AI agent. Read the README first; that part is for apps and binaries, the Netflix test above does not need it.
