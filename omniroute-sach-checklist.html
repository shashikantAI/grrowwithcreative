"Free" kitna free hai

  • OpenRouter free models (:free): 20 requests/minute, 50 requests/day agar aapne kabhi $10 se kam credits kharide hain (docs: openrouter.ai/docs/api-reference/limits). $10+ par 1000/day.
  • Gemini API free tier: Google ke apne pricing page par likha hai — "Content used to improve our products: Yes". Paid tier par nahi. (ai.google.dev/gemini-api/docs/pricing)
  • Models retire bhi hote hain: mere test mein gemini-2.5-flash ne bola "no longer available to new users".

Security — yeh zaroor karo

OmniRoute start hone par khud warning deta hai:

SECURITY: listening on 0.0.0.0 with NO API-key requirement — the inference plane (/v1/*)
is reachable by ANY device that can route to this host, and requests are billed to your
configured providers.

Aur dashboard ka default password CHANGEME hota hai.

Do kaam abhi karo:

  1. Password badlo (dashboard → settings → security).
  2. Server ko sirf apne PC tak rakho:
OMNIROUTE_SERVER_HOST=127.0.0.1
REQUIRE_API_KEY=true

Windows par ek line mein:

set OMNIROUTE_SERVER_HOST=127.0.0.1 && set REQUIRE_API_KEY=true && npx omniroute

Kab use karna chahiye

  • Haan: personal projects, learning, side projects, jahan code public ho sakta hai.
  • Nahi: office ka code, client ka data, kisi NDA wala project. Aapke prompts dusri companies ke servers par jaate hain, aur free tiers par training ke liye use ho sakte hain.
