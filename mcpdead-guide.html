MCP Code Mode — GitHub links + kaise try karein

Reel ka short answer: MCP dead nahi hai. Badla sirf tareeka hai — AI har tool ko ek-ek karke call karne ki jagah code likhta hai, jo sandbox mein chalta hai.

1,170,523tokens — Cloudflare API ke 2,594 tools, normal MCP
~1,100tokens — same API, Code Mode (search + execute)

Numbers: cloudflare/mcp README ki token table.

1. Cloudflare MCP server (reel wala Code Mode server)

Poori Cloudflare API (~2,500 endpoints) sirf ~1k tokens mein.
github.com/cloudflare/mcp

Claude Code / Cursor / kisi bhi MCP client mein ye config daalo — connect karte hi Cloudflare login (OAuth) khulega:

{
  "mcpServers": {
    "cloudflare-api": {
      "type": "http",
      "url": "https://mcp.cloudflare.com/mcp"
    }
  }
}

Comparison dekhna hai? URL ke end mein ?codemode=false lagao — har endpoint alag tool ban jaata hai (~244k tokens).

2. Apne agent mein Code Mode — @cloudflare/codemode

Tumhare tools ko TypeScript API bana deta hai; AI code likhta hai jo isolated sandbox mein chalta hai.
github.com/cloudflare/agents → packages/codemode

npm install @cloudflare/codemode agents ai zod

⚠️ Package "Experimental" hai — production mein soch samajh ke use karo.

3. Coding agent ke liye prompt (bina kisi setup ke)

Jab koi kaam bahut saare tool calls ka ho, Claude Code / Codex / Cursor ko bolo:

Don't call the tools one by one. Write one script that runs all the steps and print only the final result.

Kaam tab karta hai jab tumhare setup mein agent script chala sakta ho aur tools code se call ho sakein.
