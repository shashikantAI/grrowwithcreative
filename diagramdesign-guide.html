Diagram Design — AI diagram ko magazine jaisa kaise banao

@shashikant.ai · comment DESIGN guide · tested on 9 Oct 2026

1. Yeh folder kya hai

  • GitHub: github.com/cathrynlavery/diagram-design — 47,000+ stars, free, MIT.
  • Banane wali: Cathryn Lavery (BestSelf Co ki founder; apni site pe khud likhti hain: "an engineer who can't code from scratch but ships anyway").
  • Ek rulebook jo coding agent diagram banane se pehle padhta hai: ek accent colour, ek patli line, shadow nahi, 42 tarah ke diagram ke template (light / dark / editorial).
  • Chalta hai: Claude Code, Codex, GitHub Copilot, Factory Droid, Pi; npx skills add se Cursor, Cline, Gemini CLI aur baaki.

2. Install (do rasta)

Claude Code ke andar:

/plugin marketplace add cathrynlavery/diagram-design
/plugin install diagram-design@diagram-design

Cursor / Gemini CLI / koi bhi Agent Skills host:

npx skills add cathrynlavery/diagram-design

Phir diagram maango jaise normally maangte ho. Pehli baar yeh poochega: style guide customise karna hai? (website URL / tokens paste / default).

3. Mera test (same prompt, do baar, Claude Code 2.1.295)

Prompt: UPI payment flow ka diagram, ek self-contained diagram.html.

Bina folderFolder ke saath

Sach wali baat: time dugna laga. Jo bana woh "sundar" se zyada "consistent" hai — ek colour, ek line weight, legend. Agar tumhe rang-birangi diagram chahiye, yeh woh nahi karega.

4. Apne brand ke colour (jo maine haath se kiya)

Pehla rasta: apni website ka link do, yeh colour aur font padh ke profile banata hai.

Mere test mein (claude -p, non-interactive) network block tha, isliye isne website nahi padhi aur PROVISIONAL placeholder bana diya. Doosra rasta jo chala: tokens paste karo. Mere:

paper #F5F2FF · ink #141414 · accent #4B2BD8 · link #8C74F2 · highlight #C6F432

Bolo: "update profile with these tokens, mark confirmed, regenerate diagram-brand.html". Agla diagram tumhare brand mein.

5. Output HTML hai, image nahi

  • diagram.html offline khulti hai (inline SVG).
  • Label badalna ho: file mein text badlo, browser refresh. Dobara generate nahi.
  • PNG / SVG export: skill ke scripts (Playwright) se, PNG 2x.
  • Purani draw.io / Mermaid / Excalidraw file bhi isse dobara bana sakte ho.

6. Rule teen (yaad rakhne layak)

  1. Ek accent colour (focal cheez ke liye), baaki grey/ink.
  2. Ek patli line (1 px hairline), shadow bilkul nahi.
  3. Page pe bheed nahi: density 4/10.

7. Kab kaam nahi karega

  • Plain chat window (claude.ai / ChatGPT) mein nahi — coding agent chahiye.
  • Mera doosra test: chai cafe ka axonometric plan. Bina folder wala zyada colourful aur detailed nikla; folder wala saaf aur editorial. Taste = consistency, jaadu nahi.
