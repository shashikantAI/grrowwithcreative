Claude Code Mods — reel wale 5 mods, install commands ke saath (shashikant.ai)

Checked on 5 Oct 2026. Mod = ek chhota plugin jo Claude Code ke andar naya feature jod deta hai. Mods free hain; Claude Code khud Pro/Max plan ya API key se chalta hai.

Pehle ek baar check karo

  1. Terminal mein likho: claude --version — version 2.1.287 ya usse naya hona chahiye. Purana hai toh Claude Code update karo.
  2. Mods terminal wale Claude Code aur Desktop app ke Code tab mein dikhte hain. VS Code extension ke chat panel mein mod chalta hai, par uska design nahi dikhta.

1. cc-arcade — Claude ke andar Tetris, Snake, Doom

Banane wala: Seza Akgün · github.com/sezaakgun/cc-arcade


claude plugin marketplace add sezaakgun/cc-arcade
claude plugin install cc-arcade@cc-arcade

Phir Claude Code kholo aur likho /arcade (ya seedha /arcade tetris). Board pe click karo, arrow keys se khelo, Esc se wapas prompt pe. Claude ka kaam khatam hote hi game pause ho jaata hai.

Tip: purane Windows console mein blocks boxes jaise dikhte hain — Windows Terminal use karo.

2, 3, 4. Token Weather, Blast Radius, Replay Theater — Anthropic ke sample mods

Banane wala: Anthropic · github.com/anthropics/claude-code-playground (folder claude-code/mods)


git clone https://github.com/anthropics/claude-code-playground
claude plugin marketplace add ./claude-code-playground/claude-code/mods
claude plugin install token-weather@claude-code-playground-mods
claude plugin install blast-radius@claude-code-playground-mods
claude plugin install replay-theater@claude-code-playground-mods

Sirf ek baar try karna hai, install nahi? Toh: claude --plugin-dir ./claude-code-playground/claude-code/mods/token-weather

  • Token Weather: prompt ke upar ek patti — Claude ki memory (context) kitni bhari hai, mausam ki tarah: Clear, Showers, Storm.
  • Blast Radius: rm -rf ya force push jaise command ko rok ke dikhata hai ki kya kya delete hoga. 1 = Proceed, 2 = Cancel.
  • Replay Theater: Claude ke kaam ke baad R dabao (ya /replay likho) aur har edit ek ek karke dekho. N = next, P = previous.

Dhyan do: clone wala folder delete ya move kiya toh ye mods load hona band ho jaate hain. Aur mere Windows test mein Blast Radius error de gaya (use bash chahiye) — Mac/Linux pe maine test nahi kiya.

5. Apna khud ka mod — mera Spider Crawl

Koi coding nahi. Claude Code mein bas ye likho:


make a mod: jab bhi tum web search karo, prompt ke upar ek spider dikhao jo web pe chale, aur har site ka naam ek thread ki tarah list karo

Claude poochhega "Enable hot reloading for this session?" — Enable for this session chuno. Mod usi session mein chalu ho jaata hai. Ab likho search the web for today's India cricket score aur spider dekho.

Apna idea daalo: chai break reminder, cricket score patti, kuch bhi.

Install se pehle 1 safety check (zaroori)

Mod aapki permissions se chalta hai: files padh sakta hai, API keys padh sakta hai, har prompt dekh sakta hai. Isliye sirf bharose wale mods.

Kisi bhi mod ko install karne se pehle uska folder download karo aur chalao:


claude plugin validate ./mod-ka-folder

Output mein hooks: aur calls: lines batati hain ki mod kya kya chhoota hai. $.fs = files, $.process = programs chalana, network calls = data bahar bhejna. Samajh na aaye toh install mat karo.

Mod band kaise karein

  • Ek mod: Claude Code mein /plugin → Installed tab → disable ya uninstall.
  • Saare mods, ek session ke liye: claude --safe-mode
