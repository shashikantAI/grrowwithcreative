2. Install (Claude Code)

Sirf ek skill chahiye? Repo clone karo aur us skill ka folder copy karo:

cp -r design-skills/skills/apple ~/.claude/skills/

claude.ai pe: skill ka folder ZIP karo → Settings → Skills → Upload skill.
