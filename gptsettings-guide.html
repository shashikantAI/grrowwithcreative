ChatGPT Settings Checklist: all 18 pages, the 5 nobody shows

Checked 23 Oct 2026 on a ChatGPT Plus account on the web (chatgpt.com → your profile → Settings). Free-plan screens can differ; marked where it matters. OpenAI changes these pages often.

The 5 from the reel

1
Use reset — Settings → Usage → Usage limit resets
One tap restores your 5-hour limit, weekly limit, or both. Seen on Plus (2 resets, each with an expiry date). Not confirmed on Free.
2
Full-body reference photo — Settings → Personalization → Reference photos → Add
ChatGPT uses it "to show how clothing and accessories look on you" when you ask for an image of yourself. The face "Reference photo" sits right above it.
3
Passwords — Settings → Passwords
A built-in password manager ("Saved passwords (0)"). My call: I don't store passwords in ChatGPT. Yours is yours.
4
Pets — Settings → Pets
9 desktop companions (Codex, Dewey, Fireball, Hoots, Rocky, Seedy, Stacky, BSOD, Null Signal) + Create a pet with ChatGPT. Shows in the desktop app.
5
Trusted contact — Settings → Trusted contact → Add contact
OpenAI's own text: "In the future, if you discuss suicide with ChatGPT in a way that indicates a serious safety concern, we may automatically notify your trusted contact so they can check in with you. They must be 18+."
For parents: open it in your child's ChatGPT and add your number. It is "may notify", not a guarantee.

All 18 settings pages (what to check in each)

  1. General — app language.
  2. Appearance — theme, accent colour.
  3. Notifications — Codex tasks, group chats, Health, Library, marketing, personalised tips, projects, responses. Marketing off if you don't want it.
  4. Profile — public builder profile.
  5. Security and login — passkeys, password, MFA (authenticator / text), active sessions (log out all), security history, Advanced account security, Lockdown mode.
  6. Account — name, username, plan, delete account.
  7. Archived chats — restore or delete.
  8. Parental controls — link a teen's account, set limits.
  9. Trusted contact — see #5 above.
  10. Voice — read-aloud voice, language, dictation, last 20 recordings on this device.
  11. Storage — 20 GB quota; files and images counted separately. Clear old images here.
  12. Personalization — memory on/off, Memory summary (what ChatGPT thinks it knows about you — read it once), writing-style reference, reference photos (#2), base style and tone (warmth, enthusiasm, emoji, visual answers, headers and lists), custom instructions, Codex instructions, fast answers, web search, library search.
  13. Pets — see #4.
  14. Keyboard — shortcuts. Useful: Ctrl+Enter sends in the background, Ctrl+Shift+M picks effort.
  15. Usage — plan limits, usage history, credits, app limits, usage limit resets (#1).
  16. Billing — plan, invoices.
  17. Data controls — shared links, "Improve the model for everyone" (training on your chats — off if you want), location, export data, archive / delete all chats, cookies.
  18. Plugins (Integrations) — installed plugins and their permission level; Passwords (#3) sits under Integrations too.

3 things I'd do today

  1. Data controls → turn off "Improve the model for everyone" if your chats are work chats.
  2. Personalization → read your Memory summary once. Delete what's wrong.
  3. Security and login → MFA on, review active sessions.
