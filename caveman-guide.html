Caveman setup guide — tested by shashikant.ai

Free AI coding skill that makes Claude Code / Cursor / Codex answer short. Tested on 3 Oct 2026.

1. Install (one command)


npx skills add JuliusBrussee/caveman -g

Works in Claude Code, Codex, Gemini CLI, Cursor, Windsurf, Cline, Copilot and 30+ agents. No account, no API key.

If your agent doesn't switch on its own, type /caveman at the start of your message. Say "normal mode" to switch it off.

3. What others measured

  • JetBrains (86 real coding tasks): quality the same (8 better, 10 worse, 64 tied) — but output tokens only −8.5%, not the advertised 65%. Their verdict: "Safe, honest about style, oversold on savings."
  • CAVEWOMAN paper (arXiv, Jun 2026): output compression cut cost 1.4–2.4× per model (up to 3× best case).

    • 4. The catch

  • Savings are big on chat-style questions and explanations, small in coding-agent work (code itself is never shortened).
  • On per-request plans (e.g. GitHub Copilot premium requests) it saves nothing — a short answer is still one request.
  • The rules add ~1,000 input tokens per call, so very short one-line questions can cost more.

    • Verdict: ⚠️ Worth it for long chats, explanations and log-heavy sessions. Skip it if you only generate code or pay per request.

    5. Uninstall

    
npx skills remove caveman -g

    (The install command adds a whole pack of caveman skills — run npx skills list to see them and remove the ones you don't want.)
