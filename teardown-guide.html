TEARDOWN: turn any machine into a 3D simulator with Claude Code (DM for keyword TEARDOWN)

Free Claude Code skill by Elvar (@elvar_official), MIT licence. The reel's footage is his. Checked 2026-10-31.

1. Install (once)

npx skills add elvarofficial/teardown -g -a claude-code

Then, inside the installed skill folder:

npm install && npx playwright install chromium

Needs Node.js 20+. Video export also needs ffmpeg; sound needs Python 3.

https://github.com/elvarofficial/teardown

2. Open the 3 ready machines

node sims/build.mjs v8-live
node sims/build.mjs cessna-live
node sims/build.mjs strandbeest-live

Each becomes one offline HTML page in teardown-out/dist/. Press the buttons, orbit, cut it open.

3. The rule that matters

Always attach ONE reference picture

A cutaway drawing, a photo or a clip of the real machine. Without one, results come out like generic toys (the skill's own rule #1).

4. Five Indian machines to try

Paste into Claude Code and attach a photo. Note: I have NOT test-built these yet — they are starting prompts.

1.Pressure cooker
Build me a simulator of a pressure cooker I can take apart. One input: steam pressure. Show the weight valve lifting and the whistle, with a live pressure gauge in bar.
2.Royal Enfield 350
Build me a simulator of a Royal Enfield 350 single-cylinder engine. One input: crank angle. Cut the cylinder open and chart chamber pressure.
3.Ceiling fan
Build me a simulator of a ceiling fan motor. One input: regulator step. Show the rotor, stator coils and blade rpm.
4.Mixer grinder
Build me a simulator of a mixer grinder jar coupling and motor. One input: speed knob. Show the blade assembly exploded.
5.ATM
Build me a simulator of an ATM cash dispenser. One input: notes requested. Show the pick rollers and note counter.

Made one? Tag @shashikant.ai — I'll feature the best one.
