6 Weird Claude Code Skills (comment WEIRD)

These are the 6 slash commands from the reel, as real Claude Code skills. Copy each one into your project, type the command in Claude Code, and Claude writes the animation as code. No editing app, no video model.

How to use

  1. Install Claude Code (claude.com/claude-code) and open it inside any project folder.
  2. For each skill make a folder: .claude/skills/<name>/ (example: .claude/skills/melt/).
  3. Inside it create SKILL.md and paste the text from the box below (keep the top part between the --- lines).
  4. Restart Claude Code, type / and you will see the commands. Type /melt and press Enter.
  5. Claude builds one HTML file and opens it. Want it as an MP4? Ask: "turn this into a Remotion video and render it".

The 6 skills

1./melt

Make the current screen melt like hot wax - a 3 second animation, one HTML file

.claude/skills/melt/SKILL.md

---
name: melt
description: Make the current screen melt like hot wax - a 3 second animation, one HTML file
---
Build ONE self-contained file `melt.html` (no libraries) that plays a 3 second animation at 1080x1920:
1. Draw a dark terminal UI (window bar, a prompt line, a box that says `> /melt`).
2. Slice the whole UI into 60 vertical columns. Each column starts sagging at a slightly different time
   (smooth sine offsets, so it looks like wax, not glitch slices) and slides down with gravity.
3. Leave faint drip trails behind every column (2 copies at 30% and 60% of the fall, 20% opacity).
4. A wavy puddle (orange -> violet -> lime gradient) rises from the bottom as the screen drips into it.
5. A few drops fall separately. Loop forever. Open it in the browser when done.
2./chai-chart

Turn numbers into a bar chart made of cutting-chai glasses that fill up with steam

.claude/skills/chai-chart/SKILL.md

---
name: chai-chart
description: Turn numbers into a bar chart made of cutting-chai glasses that fill up with steam
---
Ask me for 5 labels + numbers (default: chai cups per day MON 3, TUE 4, WED 6, THU 5, FRI 9).
Build ONE file `chai-chart.html` (SVG + JS, no libraries), 1080x1920, warm dark-brown background:
- Each bar is a cutting-chai glass (trapezoid, wider at top, 7 vertical ridges). Glass HEIGHT = the value.
- Glasses spring up one by one, then chai pours in from above and fills each to 86%, a foam ellipse on top.
- The number above each glass counts up while it fills; steam curls rise after it is full.
- Title + unit on top ("OFFICE CHAI / cups per day"). Highlight the biggest value in lime #C6F432.
Open it in the browser when done.
3./shatter

Crack the screen like glass from a tap point and blow the pieces apart in 3D

.claude/skills/shatter/SKILL.md

---
name: shatter
description: Crack the screen like glass from a tap point and blow the pieces apart in 3D
---
Build ONE file `shatter.html` (no libraries), 1080x1920:
1. Show any UI (a terminal with `> /shatter`).
2. A tap at (540, 880): white crack lines draw outward like a spider web (12 angle sectors x 4 rings, jittered).
3. Every cell becomes a shard: a copy of the UI clipped with clip-path polygon.
4. After 0.4 s the shards fly outward in 3D (perspective 1500px): speed by direction, gravity, random rotateX/rotateZ, translateZ.
5. Behind them reveal the shard count in big lime text: "48 PIECES - every piece = a few lines of code".
Replay on click. Open it in the browser when done.

---
name: xray

5./ants

Hundreds of ants walk in from the edges and write your text

.claude/skills/ants/SKILL.md

---
name: ants
description: Hundreds of ants walk in from the edges and write your text
---
Ask me for the text (default "CLAUDE DID THIS", 3 lines). Build ONE file `ants.html` (canvas, no libraries), 1080x1920, cream paper background:
1. Draw the text on a hidden canvas (900 weight, ~200px), sample a point every 15 px inside the letters -> one ant per point.
2. Each ant starts on a big circle outside the screen, walks to its point with a wiggle, legs moving, body rotated along its path.
3. Ants arrive at random times over ~2 s, then fidget in place. Show a counter "ANTS ARRIVED: n / total".
Open it in the browser when done.
6./this-reel

Rewind the video you just made and reveal its own source code scrolling past

.claude/skills/this-reel/SKILL.md

---
name: this-reel
description: Rewind the video you just made and reveal its own source code scrolling past
---
For the reel/animation in this folder:
1. Add an ending: everything rewinds fast (reverse playback, scanlines, a REWIND badge).
2. Then the screen becomes the REAL source code of the animation itself, scrolling, with simple syntax colours,
   the file name and its line count on top.
3. Over it, two cards: "poori reel = CODE" then "EDITING APP: 0".
Use the actual file contents (read them, never invent code). Open the result in the browser when done.
