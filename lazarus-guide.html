5 checks before you download an AI model (shashikant.ai)

Microsoft researchers showed that editing fewer than 10 neurons can hide a backdoor in an AI model, and normal tests still look fine (paper: "Lazare, veni foras", Microsoft Research + Microsoft AI Red Team, Nov 2026). It is a research demonstration, not an attack seen in the wild. It matters when you download a model and let an AI agent run commands with it. These 5 checks are the paper's own advice to users, with how to do each.

1. Download only from the original company's account

  • On Hugging Face, look at the account name before the slash: Qwen/Qwen3.6-27B is Qwen's own account. A name like someuser/Qwen3.6-27B-... is someone's copy or modified version.
  • Open the model page and check Model tree → Base model: it tells you which original model this one was made from.
  • A search for one model name showed 3,144 results on 14 Nov 2026. High downloads do not tell you which one is original.

2. Check that the file you got is the file they published

  • On the model's Files tab, click the file → copy the SHA256 shown there.
  • Windows: certutil -hashfile model.safetensors SHA256 · Mac / Linux: shasum -a 256 model.safetensors
  • The two must match exactly. This proves nobody changed the file on the way. It does NOT prove the model is safe.

3. Give the agent only the access it needs

  • Run the agent in one project folder, not your whole home folder.
  • Keep passwords, API keys and SSH keys out of that folder and out of the terminal it uses.
  • For a model you do not fully trust, run the agent inside a container or a virtual machine with no saved logins.

4. Approve risky commands yourself, and keep a log

  • Leave "ask before running commands" ON. Do not use auto-approve / "yolo" mode with a downloaded model.
  • Read any command that downloads and runs something in one line, like curl ... | sh. Say no if you did not ask for it.
  • Keep the agent's command log so you can see later what it ran.

5. A passed test is not proof of safety

  • The edited model in the paper scored almost the same on normal tests (0.4659 → 0.4205 on one benchmark) and still obeyed the hidden trigger.
  • So treat "popular", "benchmarked" and "scanned" as evidence, not a guarantee. Checks 1–4 are what limit the damage.

Source: https://anadim.github.io/papers/Lazarus.pdf
