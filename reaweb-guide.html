1. What you need

  1. Node.js 18 or newer (nodejs.org, LTS button). Check: node -v
  2. Google Chrome (normal install path).
  3. Python 3 only for step 4 (optional).

REA is free and open source: github.com/morluto/rea. Nothing is installed globally; npx downloads it the first time.

2. Save as flipkart.json 

{
  "browser": { "mode": "launch", "executable_path": "C:/Program Files/Google/Chrome/Application/chrome.exe", "headless": false },
  "start_url": { "url": "https://www.flipkart.com/" },
  "actions": [
    { "step_id": "home",    "action": "wait_for_timeout", "duration_ms": 8000 },
    { "step_id": "search",  "action": "goto", "destination": { "url": "https://www.flipkart.com/search?q=iphone%2016" }, "wait_until": "load" },
    { "step_id": "results", "action": "wait_for_timeout", "duration_ms": 10000 }
  ],
  "capture": { "after_each_step": ["url"], "at_end": ["url", "screenshot"], "events": ["network"],
               "network": { "request_body": false, "response_body": true, "header_values": false } }
}

Keep the forward slashes / in the Chrome path. Mac: /Applications/Google Chrome.app/Contents/MacOS/Google Chrome.
Any other website: change the two URLs (the homepage + one search or product page of that site). That's all.

3. Run REA (same folder) 

npx -y rea-agents@6.4.0 capture-browser-scenario flipkart.json --format json > flipkart-capture.json

Chrome opens, REA does the steps by itself and closes it. flipkart-capture.json is big (20–40 MB) because it keeps the code your browser received.

4. Quick count (optional) 

import json, sys, collections, base64, urllib.parse
d = json.load(open(sys.argv[1], encoding="utf-8"))["normalized_result"]["events"]["items"]
reqs = {e["transaction_id"]: e for e in d if e.get("kind") == "request"}
types = collections.Counter(e.get("resource_type") for e in reqs.values())
print(len(reqs), "requests |", types["script"], "JS files |", types["image"], "images |", types["fetch"] + types["xhr"], "data calls (fetch/xhr)")
size = {}
for e in d:
    b = e.get("body") or {}
    if e.get("kind") == "network-content" and e.get("phase") == "response" and isinstance(b, dict) and b.get("content"):
        raw = b["content"]
        size[e["transaction_id"]] = len(base64.b64decode(raw)) if b.get("encoding") == "base64" else len(raw.encode())
js = [(size.get(t, 0), r["url"]["url"]) for t, r in reqs.items() if r.get("resource_type") == "script"]
print(f"JS code received: {sum(s for s, _ in js) / 1e6:.1f} MB (decoded)")
for s, u in sorted(js, reverse=True)[:8]:
    print(f"{s / 1e6:6.2f} MB  {urllib.parse.urlparse(u).path[-70:]}")
hosts = collections.Counter(urllib.parse.urlparse(r["url"]["url"]).hostname for r in reqs.values() if r.get("resource_type") in ("fetch", "xhr"))
print("API hosts:", ", ".join(f"{h} ({c})" for h, c in hosts.most_common(6)))
