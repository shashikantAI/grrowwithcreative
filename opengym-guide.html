2. Pehle demo try karo (2 minute)

  1. opengym.ch/demo kholo. Example data pehle se bhara hai.
  2. Neeche Stats dabao → Muscle balance: is hafte kis muscle ne kitne sets kiye.
  3. Fatigue tab: laal = thaka hua (rest do), peela = recover ho raha.
  4. Thoda neeche: "Not trained in this period" = jo muscle aap skip kar rahe ho.
  5. Exercises tab: 5,632 exercises, har ek ka animation, kaam karne wala muscle laal mein.

3. Ye kaise jaanta hai?

Har exercise ke saath uske muscles tagged hain (jaise squat → quads, glutes). Aap jo set log karte ho, app us muscle ke khaate mein gin leta hai. Hafte bhar mein jis muscle ka count zero, wo "Not trained" mein aata hai.

4. Phone par kaise chalayein

PhoneKaise
AndroidGitHub Releases se signed APK download karke install karo (Play Store par nahi hai). Settings mein "install unknown apps" allow karna padega.
iPhoneApp Store par nahi hai. Apne computer/server par openGym chalao (Docker), phir Safari se "Add to Home Screen".
Computer / servergit clone → docker compose up → browser mein localhost:8080. Steps: GitHub README "Quick start".

5. Purani history laao

Settings → Data & backup → Import from another app: FitNotes, Strong, Hevy (CSV), ya Apple Health ka weight. Hevy Pro ho toh API key se bhi.

6. Claude se poochna (optional)

Repo mein ek MCP server hai: Claude Desktop aapka training log padh sakta hai (read-only, local) aur poochne par bata sakta hai kaunsa muscle skip ho raha hai. Ye by default off hai aur Docker build ka hissa nahi. Steps: repo ka mcp/ folder.

7. Sach wali baat

Android par APK sideload karna padta hai, iPhone par sirf web app (apna server chahiye). Exercise animations open source license mein nahi aate (sirf openGym ke liye licensed). Demo ka data example hai, aapka data aapke server par rehta hai.
