Install (one time)

  1. Install Python 3.10+ from python.org. Tick "Add to PATH".
  2. Download the tool: git clone https://github.com/hugohe3/ppt-master (or Code → Download ZIP on GitHub).
  3. Open that folder in a terminal and run: pip install -r requirements.txt
  4. Start Claude Code in the same folder: claude. Windows help: docs/windows-installation.md in the repo.

My prompt

Change the PDF path and the audience.

Make a PowerPoint from the PDF <path to your PDF> using the quick/fast generate route (no confirmation questions, decide everything yourself). 16:9, about 10 slides, English, audience = <who will watch>. Use native PowerPoint charts and tables (--native-charts-and-tables) for the numbers. Export the final .pptx and print its absolute path at the end.

Your file lands in projects/<name>/exports/*.pptx. Open it in PowerPoint: every text box and chart is editable (chart → Edit Data).

Honest notes

  • Best results with Claude (paid plan). The tool is free; your AI model usage is your cost.
  • NotebookLM's slides look flashier, but its PowerPoint export is one picture per slide.
  • First drafts are plain. Polish them in PowerPoint; that's the point of editable slides.
