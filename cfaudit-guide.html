Cloudflare Security Audit Skill — free pack (shashikant.ai)

Tested by me on a 45-line Flask app with 6 bug groups I planted: it found all 6. Source: https://github.com/cloudflare/security-audit-skill (MIT, free).

1. Install (inside your project folder)

Tool: terminal. This is the command from the repo README.

npx skills add https://github.com/cloudflare/security-audit-skill --skill security-audit

2. Run it

Tool: Claude Code, opened in the same project. Type:

security audit this codebase

3. Read the report

VerdictMeaning
CONFIRMEDthe skill reproduced the bug in a sandbox
NEEDS VALIDATIONthe code says yes, but it was not run, so check it yourself
REJECTEDa second agent disproved it

Each finding has a source trace (file:line) and a suggested fix. Fix the NEEDS VALIDATION ones first if they touch login, admin pages, file download or SQL.

4. Turn a finding into a fix

Tool: Claude Code. Paste:

Fix finding #1 from the audit report. Use the source-level fix it suggests, then add a regression test that fails before the fix and passes after.

5. Honest catches from my test

  • Full run on a tiny file: 24 agents, about 15 minutes, about $6.5 at API prices. A quick single-agent pass took 107 seconds and about $0.39 but has no second-agent checking.
  • On Windows I got 0 confirmed, 7 needs validation, because the full audit only confirms bugs inside an OS sandbox and Windows had none. Use Linux, macOS or WSL if you want confirmed results.
  • Cloudflare says repeated runs find more bugs, so one run is not a final clearance.
  • A clean report does not mean the app is safe.
  • Run it on your own code only, and never point it at a live site you do not own.
