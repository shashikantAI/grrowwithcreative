MarkItDown setup guide

Claude har PDF page ko text + ek image bana kar padhta hai (Anthropic ke PDF-support docs). Isliye bade PDF limit jaldi kha jaate hain. Fix: file ko pehle Markdown mein badlo — sirf text jaata hai. Tool: MarkItDown by Microsoft, free, open source, 186K+ stars — github.com/microsoft/markitdown

Step 0 · ek baar

Python chahiye

Python 3.10 ya upar. Check karo:

python --version

Nahi hai to python.org/downloads se install karo (Windows par Add python.exe to PATH tick karna).

Step 1

Install

pip install "markitdown[all]"

[all] se PDF, Word, Excel, PowerPoint sab formats aa jaate hain.

Step 2

Convert

markitdown budget.pdf -o budget.md

Hamara real test: Union Budget 2026-27 speech, 65 pages → Markdown in 2.1 seconds (command start-to-finish ~3 s, Python load time mila ke). File 662 KB se 112 KB.

Step 3

Yahi .md file Claude ko do

PDF ki jagah .md file upload karo (ya text paste karo). Same content, koi page image nahi.

InputCommand
Wordmarkitdown report.docx -o report.md
Excelmarkitdown data.xlsx -o data.md
PowerPointmarkitdown deck.pptx -o deck.md
HTML / CSV / JSON / ZIPsame pattern
  • Word files sabse saaf aate hain — headings aur tables dono bache rehte hain (tested).
  • YouTube link ka feature repo mein likha hai, lekin hamare test mein transcript nahi aaya — us par bharosa mat karo.

The setting

Claude Desktop ke andar — no terminal after setup

MarkItDown ka apna official MCP server hai. Ek baar connect karo, phir Claude khud convert karke padh leta hai.

1. Install:

pip install markitdown-mcp

2. Claude Desktop → Settings → Developer → Edit Config. claude_desktop_config.json mein ye add karo:

{
  "mcpServers": {
    "markitdown": {
      "command": "markitdown-mcp"
    }
  }
}

Agar "command not found" aaye to poora path do. Path nikalne ke liye: Windows where markitdown-mcp, Mac/Linux which markitdown-mcp.

3. Claude Desktop band karke dobara kholo. Tools mein convert_to_markdown dikhega.

4. Use — chat mein likho:

Convert C:\Users\me\Documents\budget.pdf to markdown and summarise it.
  • Claude tool call karega, file Markdown mein badlegi, aur wahi padhega. Hamara test: same 65-page PDF, 2.3 s.
  • Ye tool file path ya URL leta hai. Chat mein drag-drop ki hui file par ye apne aap nahi chalta — path do.

Sach

Limits

  • Scanned PDF (photo jaisi pages): text nikalta hi nahi — OCR nahi hai. (Hamara test: scanned page → khaali .md file.)
  • 2-column kitaabein (jaise NCERT chapters): dono columns ki lines mix ho jaati hain.
  • Kuch PDFs mein words ke beech ke spaces gayab ho jaate hain. Convert ke baad .md file ek baar khol kar dekh lo.
  • Charts / diagrams ka matlab chahiye? Tab original PDF hi do — Claude image se hi unhe samajhta hai.
  • Best: normal text PDFs (reports, speeches, contracts, Word se bane PDFs), aur Word / Excel / PowerPoint files.
