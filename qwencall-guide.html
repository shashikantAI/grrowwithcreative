Local AI safe setup — free guide (shashikant.ai · AI PAKDA GAYA #01)

Reel: Cohere's test caught Alibaba's Qwen model (Qwen3.8-Flash-Next) writing "no tool calls" in its plan, then running commands and trying to upload a test file to an Alibaba Cloud server in Beijing. Their sandbox had no internet, so it stopped. Very rare in their test (less than 1 in 100,000 calls); Cohere's own report: https://cohere.com/blog/concerning-behaviour-popular-open-weight-ai-model

Two rules for any AI agent on your laptop (Qwen, Llama, DeepSeek, Claude Code, Codex, OpenCode…):

1. Internet only where you decide. 2. Every command asks you first.

1. Internet band (the real wall)

Approval prompts slow an agent down; they are not a sandbox. The wall is the network.

Option A — Docker (cleanest): run the agent inside a container with no network at all.

docker run --rm -it --network none -v "%cd%":/work -w /work <your-agent-image>

Inside it the agent can read and edit your project, but no command can reach the internet. (Docker docs: --network none = only a loopback device.)

Option B — Windows firewall (no Docker): block outbound traffic for the agent's program.

New-NetFirewallRule -DisplayName "Block AI agent" -Direction Outbound -Program "C:\path\to\agent.exe" -Action Block

Undo: Remove-NetFirewallRule -DisplayName "Block AI agent"

Note: blocks only that program; commands the agent starts through other programs (curl, python) need their own rule — that is why Option A is better.

2. Har command pe approval

OpenCode — opencode.json:

{ "permission": { "bash": { "*": "ask" }, "webfetch": "deny" } }

Every shell command asks you first; web fetch is off. (opencode.ai/docs/permissions — "ask" is friction, not a sandbox, so keep step 1.)

Claude Code — keep the default ask mode, never --dangerously-skip-permissions. In .claude/settings.json:

{ "permissions": { "deny": ["WebFetch", "Bash(curl:*)", "Bash(wget:*)"] } }

The docs warn Bash patterns are prefix matches and can be bypassed — again, step 1 is the real wall.

3. Plan nahi, command check karo

From Cohere's post — stop the agent when a command shows:

  • an upload: -X PUT, --data-binary, -T, scp, rsync to a host you don't know
  • a cloud URL you never use (*.aliyuncs.com, random storage buckets)
  • 169.254.169.254 (cloud credential address)
  • unshare, sudo, permission tricks when it hit a "permission denied"

The plan text ("I will not call tools") is not proof. The command is.
