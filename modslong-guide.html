Claude Code Mods — video wale 7 mods, install commands ke saath (shashikant.ai)

Checked on 6 Oct 2026. Mod = ek chhota plugin jo Claude Code ke andar naya feature add kar deta hai. Yeh saare mods free hain; Claude Code khud Pro/Max plan ya API key se chalta hai.

Pehle ek baar check karo

  1. Terminal mein likho: claude --version — version 2.1.287 ya usse naya hona chahiye. Purana hai toh Claude Code update karo.
  2. Mods terminal wale Claude Code aur Desktop app ke Code tab mein dikhte hain. VS Code extension ke chat panel mein mod chalta hai, par uska design nahi dikhta.
  3. Install ke baad Claude Code dobara open karo (ya chalti session mein /reload-plugins likho).

1. Guardrails — files safe (delete / force push rok deta hai)

Banane wala: mishgoldenberg · github.com/mishgoldenberg/claude-mods (MIT)


claude plugin marketplace add mishgoldenberg/claude-mods
claude plugin install guardrails@claude-mods

Claude jab rm -rf, force push, .env padhna jaisi command chalane wala hota hai, mod usko pehle hi rok deta hai aur red alert dikhata hai. Yaad rakho: yeh sirf jaani-pehchani commands pakadta hai — seat belt hai, poori safety nahi (unke apne README ke words: "a seatbelt, not a sandbox").

2. Token Weather — context window = mausam

Banane wala: Anthropic ka sample mod · github.com/anthropics/claude-code-playground (folder claude-code/mods)


git clone https://github.com/anthropics/claude-code-playground
claude plugin marketplace add ./claude-code-playground/claude-code/mods
claude plugin install token-weather@claude-code-playground-mods

Prompt ke upar ek patti: context window kitni bhari hai — Clear (25% se kam), Cloudy (25–49%), Showers (50–74%), Storm (75–89%), Compact soon (90%+). Storm dikhe toh /compact karo ya nayi chat start karo.

Dhyan do: clone wala folder delete ya move kiya toh yeh mod load hona band ho jaata hai.

3. Replay Theater — har change ka replay

Same marketplace (upar wala clone):


claude plugin install replay-theater@claude-code-playground-mods

Claude ka kaam khatam hone ke baad R dabao (ya /replay likho) aur har edit ek ek karke dekho. N = next, P = previous, C = close.

4. Burn Meter — five hour + weekly limit live

Banane wala: OneWave-AI · github.com/OneWave-AI/claude-code-mods (MIT)


claude plugin marketplace add OneWave-AI/claude-code-mods
claude plugin install burn-meter@claude-code-mods

Prompt ke upar: session ka kharcha, 5-hour limit aur weekly limit ki bars, aur dono kab reset hongi.

5. Prompt Coach — send se pehle clear prompt

Same marketplace jaisa Guardrails (mishgoldenberg):


claude plugin install prompt-coach@claude-mods

Aapka prompt send hone se pehle padhta hai aur ek clear version dikhata hai. Aap choose karte ho: Send improved / Send mine / Edit. Kabhi chupke se nahi badalta.

6. cc-arcade — Claude ke andar Tetris, Snake

Banane wala: Seza Akgün · github.com/sezaakgun/cc-arcade (MIT)


claude plugin marketplace add sezaakgun/cc-arcade
claude plugin install cc-arcade@cc-arcade

Claude Code mein /arcade likho (ya /arcade tetris). Arrow keys se khelo, Esc se wapas. Claude ka kaam khatam hote hi game pause ho jaata hai.

Tip: purane Windows console mein blocks boxes jaise dikhte hain — Windows Terminal use karo.

7. Apna khud ka mod — 0 line code

Claude Code mein simple words mein likho ki aapko kya chahiye. Mera prompt:


make a mod: jab bhi tum web search karo, prompt ke upar ek spider dikhao jo web pe chale

Claude poochhega "Enable hot reloading for this session?" — Enable for this session chuno. Mod usi chat mein chalu ho jaata hai. Apna idea daalo: chai break reminder, cricket score patti, paani peene ki yaad — kuch bhi.

Install se pehle 1 safety check (zaroori)

Mod aapki hi permissions se chalta hai: files padh sakta hai, API keys padh sakta hai, aapka har prompt dekh sakta hai. Anthropic khud kehta hai: mods sandboxed nahi hain. Isliye sirf bharose wale mods.

Kisi bhi mod ko install karne se pehle uska folder download karo aur chalao:


git clone https://github.com/mishgoldenberg/claude-mods
claude plugin validate ./claude-mods/plugins/guardrails

Output mein hooks: aur calls: lines batati hain ki mod kya kya chhoota hai — $.fs = files, $.process = programs chalana, network calls = data bahar bhejna. Samajh na aaye toh install mat karo.

Mod band kaise karein

  • Ek mod: claude plugin disable guardrails@claude-mods (ya Claude Code mein /plugin → Installed → disable / uninstall).
  • Saare mods, ek session ke liye: claude --safe-mode
