Anime in HTML — repo + my shot sheet + exact prompt

Tested 24 Oct 2026 on Windows 11 with Claude Code. A 12-second, 1080×1920 anime: every frame HTML + CSS, no AI video model.

1The repo (free, MIT)

github.com/blixvip/html-anime — 148 stars on 24 Oct 2026. Needs Python (local server) and Node.js (preview / render).

git clone https://github.com/blixvip/html-anime.git
cd html-anime
python -m http.server

Open http://localhost:8000. The sheet maker only works when the folder is served; opening index.html as a file will not run it.

2Make the shot sheet (one line)

On the site: write your scene, pick 12s, 9:16, colour script Vermilion eclipse, then Copy sheet. My exact line (copy it, change the scene):

A teenage boy in a torn school uniform stands on a rain-soaked Mumbai rooftop at night, city towers behind him. Red lightning crackles up his arm, his hair whips upward, and he punches the sky, blasting the storm clouds apart in a shockwave.

Tip: write a VERB scene (punch, run, jump). The sheet gives the verb the one "expensive" shot with 8 drawings; a calm scene looks like a slideshow.

3Paste it into Claude Code

Open Claude Code inside the html-anime folder and paste the copied sheet as your first message. Codex, Cursor and Grok also work (the repo has their rule files). Claude reads the repo's 5 skills and writes films/<name>/index.html. Mine took about 20 minutes.

4Watch it / make an mp4

cd films/<name>
npx hyperframes preview
npx hyperframes render --fps 24 -o anime.mp4

5The edit trick from the reel

Ask Claude to put the rain on ONE CSS variable:

:root { --rain: 0.6; }   /* 1 = cloudburst */

Change 0.6 → 1 (in the file, or live in Chrome: right-click → Inspect → Styles) and the rain gets heavier. Colours and timing are plain numbers in the same file.

6My full shot sheet

sky #2a1016 · ink #14080c · moon #100608 · accent #ff3b3b · practical #f3f6ff

Character acting on twos; rain, sparks on ones. Sakuga shot: 8 drawings, others 3. Holds ≥ 12 frames.
1 · Establish 0.00–2.50 — the place, figure small, one camera move 100%→106%
2 · Approach 2.50–5.00 — a cut closer, who is there, no second camera move
3 · Sakuga 5.00–9.00 — the verb: anticipate, action, 1–2 smear frames, settle, camera locked
4 · Button 9.00–12.00 — hold, fade the last 8 frames to ink
No dialogue, no mouth shapes, no captions.

Honest notes

  • It is simple 2D cut-out animation, not Ghibli. Bodies are boxy vector shapes.
  • The first try came out calm and flat; asking for an action verb in the line fixed it.
