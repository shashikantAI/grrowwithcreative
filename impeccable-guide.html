Impeccable — AI website ko insaan jaisa design kaise do

@shashikant.ai · comment DESIGN guide · tested on 6 Oct 2026

1. Teen nishaan jo AI website ko pakad lete hain

  1. Heading ke upar chhota label (pill / "kicker") — jaise "MADE IN MUMBAI, EVERY MORNING".
  2. Har card ke upar icon ka dabba — rounded square tile with an icon. Detector ise kehta hai: "the universal AI feature-card template".
  3. Halka cream / beige background — rgb(255, 248, 239) jaisa.

Kisi bhi website par ye teen dikhe, to zyada chance hai ki AI ne banayi hai.

2. Impeccable kya hai

  • GitHub: github.com/pbakaus/impeccable — 77,000+ stars, free, Apache-2.0.
  • Banane wale: Paul Bakaus (jQuery UI, ex-Google Chrome team).
  • Design rulebook + detector jo AI coding tools ko "AI jaisa" design banane se rokta hai.
  • Chalta hai: Claude Code, Cursor, GitHub Copilot, Codex CLI, Gemini CLI aur aur bhi.

3. Install (ek command)

npx impeccable install

Aapka AI tool detect karke skill install ho jaati hai. Update: npx impeccable update

4. Purani website check karo

npx impeccable detect https://aapki-site.com

Har AI nishaan ki list milti hai. Local file ke liye: npx impeccable detect index.html

5. Kaise kaam karta hai (3 step)

  1. AI code likhne se pehle rulebook padhta hai.
  2. Page banne ke baad detector 60 rules se check karta hai aur har nishaan ka naam leke list banata hai.
  3. AI wahi list padh kar page khud dobara likhta hai, jab tak nishaan kam na ho.
