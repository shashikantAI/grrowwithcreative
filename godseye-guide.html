Easiest: no coding (Pinokio)

  1. Install or update Pinokio (8.2 or later): desktop.pinokio.co
  2. Open God's Eye View in Pinokio.
  3. Click Install, then Start. It opens in your browser.

Terminal route (what I used)

Needs Node.js 24.x.

git clone https://github.com/bilawalsidhu/gods-eye-view.git
cd gods-eye-view
npm ci
npm run dev

Open http://localhost:4173 and pick Explore Manually.

India in 3 clicks

  1. LOCATION (bottom) → search Delhi (or your city / airport).
  2. DATA LAYERS → Live Flights ON, wait ~20 s: every plane shows its flight code (IGO = IndiGo, AIC = Air India).
  3. Click a plane: the camera locks on; COCKPIT rides along with speed + height.

Also try: Satellites ON, Earthquakes ON, keys 1–7 for night vision / thermal looks.

Honest notes

  • Free with no key: map, flights, satellites, earthquakes, weather.
  • The ground photo is old satellite imagery, not live. You will not see people.
  • Live CCTV only in a few foreign cities (Austin, London, Finland…), none in India.
  • Ships need a free AISStream key; photo-real 3D needs a free Cesium ion token (personal use).
