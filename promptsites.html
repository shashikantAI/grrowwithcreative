Free AI Prompt Websites — the PROMPT list (by @shashikantai)

Sab free. Browse + copy ke liye login nahi chahiye (image generate karne ke liye kuch sites par account lagta hai). Checked on 1 Oct 2026.

1. Image prompts (photo, portrait, poster)

  • youmind.com/prompts — 30,000+ prompts, result image ke saath. Filters: GPT Image, Nano Banana Pro, Seedream.
  • meigen.ai — category wise gallery: Portraits, Posters, Brand & Logo, Wallpaper, Illustration & 3D. Image-to-Prompt tool bhi.
  • nanobanana.im/prompts — Nano Banana ke tested prompts (transform, portrait, product, polaroid).
  • newbananaprompts.com — creators ke real prompts, exact settings ke saath.
  • promptfrenzy.com — 1,000+ image prompts for ChatGPT, Nano Banana, Midjourney, Flux.
  • github.com/YouMind-OpenLab/awesome-nano-banana-pro-prompts — 10,000+ prompts, 16 languages, open source.

2. Video prompts (Veo, Sora, Kling, Seedance)

  • ulazai.com/directory — 1,945+ prompts, har prompt ke saath woh video jo usse bana.
  • youmind.com/prompts/video — Seedance / Veo / Grok video prompts, roz naye.
  • imaginetovideo.com/prompt-gallery — 1,000+ curated video prompts, weekly update.
  • lzyprompt.com/prompts — 46 copy-paste collections by look / shot / format.

3. Text prompts (ChatGPT, Claude, Gemini)

  • prompts.chat — the original "awesome-chatgpt-prompts", 171K+ GitHub stars; search by resume, email, study, coding.
  • docs.anthropic.com → Prompt Library — Anthropic ki official library.
  • aistudio.google.com → Prompt Gallery — Google ki official Gemini gallery, prompt wahin run karo.

4. Photo → Prompt (reverse)

  • pixtoprompt.com — photo upload karo, prompt mil jata hai; Midjourney / Flux / Gemini-Nano Banana / ChatGPT format mein. Login nahi.
  • reprompt.org — same, unlimited, no signup; Android app bhi hai.

Reverse prompt kaise use karein (30 sec)

  1. pixtoprompt.com kholo → "Drop an image" → apni ya koi bhi photo daalo.
  2. 15–20 sec analysis → "Gemini · Nano Banana" tab tap karo → Copy prompt.
  3. Gemini app mein apni photo attach karo + yeh prompt paste karo → generate.

Note: reverse prompt LOOK deta hai (kapde, lighting, background). Apna face chahiye toh apni photo attach karni zaroori hai.
