pxpipe ka poora test: Claude bill kam hua ya zyada?

@shashikant.ai · comment BILL guide · tested 8–9 Oct 2026 on my own Claude Code

1. Trick kya hai

pxpipe (github.com/teamchong/pxpipe) ek local proxy hai. Claude Code ke rules, tools aur purani baatein text ki jagah PNG photo bana ke bhejta hai.

  • Daava (README): bill 59–70% kam.
  • Ek developer ka naap (dev.to, 7 Oct 2026, Opus): kharcha +196.7%.

2. Mera setup

  • Claude Code (mera account), pxpipe-proxy v0.14.0, local proxy 127.0.0.1:47821
  • Same folder: 50 React .tsx files (577 KB)
  • Chhota kaam: "Which file renders a terminal window? Answer with the filename only." (2 baar)
  • Lamba kaam: "Read every .tsx file one by one … then output a table: file, component name, number of props."
  • Har run naya session, bill = Claude Code ka apna total_cost_usd (list price)

Sahi jawab (lamba kaam): bina pxpipe 50/50. pxpipe ke saath 2 galat (PromptTicket 17 ki jagah 15, TokenChop 18 ki jagah 17), koi error nahi.

5. Bill kyun badhta hai

  • Claude ka cache pehle se dohraaye text ko 90% sasta (0.1×) padhta hai.
  • Har nayi photo pehli baar cache write hoti hai (1.25×). Naya session = naye photo = naya kharcha.
  • Isliye chhote kaam / naye session mein loss, aur sirf lambe kaam mein thodi bachat (metro pass jaisa).

6. Kab try karein, kab nahi

  • ✅ Fable + ghanton lamba session: bachat ho sakti hai (maine sirf 2–3 min ka kaam test kiya).
  • ❌ Opus 5.5: mere test mein 60% mehenga.
  • ⚠️ Exact numbers / code values wale kaam: jawab khud check karo.
  • Sonnet / Haiku: pxpipe by default inhe chhoota hi nahi.

7. Koi bhi token tool khud kaise test karein (5 min)

# 1. bina tool
claude -p "<same task>" --output-format json --allowedTools "Read,Glob,Grep" > base.json
# 2. tool ke saath (proxy wale tools ke liye)
ANTHROPIC_BASE_URL=http://127.0.0.1:47821 claude -p "<same task>" --output-format json --allowedTools "Read,Glob,Grep" > tool.json
# 3. asli bill compare karo
python -c "import json;print(json.load(open('base.json'))['total_cost_usd'], json.load(open('tool.json'))['total_cost_usd'])"

Same task, same model (--model), 2–3 baar. Tool ka dashboard nahi, total_cost_usd dekho.

8. Mera rule

Tool ka dashboard sirf andaaza hai. Asli sach sirf tumhara bill batata hai.
