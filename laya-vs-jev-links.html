Laya vs Jev: all the links

Every source from the reel, so you can check it yourself, plus how to try Laya free.

The story in 30 seconds

  • Jev is a "System One" decision model by TypeSafe AI (founder Diogo Almeida, ex-OpenAI), launched 15 Sep 2026. It doesn't write text. It returns typed decisions with a confidence score.
  • Laya is a free, open-source model by Nandakishor Mukkunnoth (ConvAI Innovations, Kasaragod, Kerala). It came out a few days later.
His claim: he published the same core idea in a research paper in March 2025. This is a claim, not proven. TypeSafe has not replied publicly, and TypeSafe says it worked in stealth for two years.

Try Laya free (Python 3.10+)

python -m pip install laya
from laya import Router

router = Router()
state = "Hi, we were billed twice for March. Please refund the duplicate."
questions = {
    "department": {"type": "choice", "instructions": "Which department?",
                   "criteria": {"billing": "invoices, payments, refunds",
                                "technical": "bugs, outages"}}
}
result = router.predict(state, questions)
print(result["answers"]["department"]["choice"])  # billing

It runs on a normal CPU (slower, a few hundred ms per question) or a GPU. Test it on your own data before you trust it for anything important.
